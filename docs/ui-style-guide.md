# All AI agents and developers must follow this style guide when implementing or modifying UI.

## UI Style Guide (MVP образовательной платформы)

Этот документ является единым источником правил для UI/UX в проекте. Любые будущие изменения интерфейса должны соответствовать этим правилам.

## 1. Язык интерфейса

- Весь пользовательский текст в интерфейсе должен быть на русском языке.
- Это относится к:
  - кнопкам;
  - лейблам;
  - заголовкам;
  - placeholder-текстам;
  - статусам;
  - сообщениям об ошибках;
  - навигации.
- Исключение: название проекта/сайта может оставаться без изменений.
- Тон текста: понятный, формальный, но простой; уместный для образовательной платформы.

## 2. Визуальный стиль

- Стиль: современный чистый LMS, вдохновленный SkillSpace.
- Основа:
  - светлые фоны;
  - зеленый акцент;
  - slate/dark блоки для контраста;
  - скругленные элементы;
  - четкая визуальная и типографическая иерархия.

## 3. Цветовая система (TailwindCSS)

Использовать только эти классы как базовую палитру:

### Primary (green accent)

- `bg-emerald-500`
- `hover:bg-emerald-600`
- `text-emerald-500`
- `border-emerald-500`

### Secondary (slate/dark)

- `bg-slate-800`
- `bg-slate-900`
- `text-slate-100`
- `text-slate-400`

### Neutral / background

- `bg-white`
- `bg-gray-50`
- `border-gray-200`
- `text-gray-700`
- `text-gray-500`

### States

- success: `text-emerald-500` / `bg-emerald-100`
- error: `text-red-500` / `bg-red-100`
- warning: `text-yellow-500` / `bg-yellow-100`

## 4. Компоненты UI

### Кнопки

- Primary:
  - `bg-emerald-500 text-white rounded-xl px-4 py-2`
  - `hover:bg-emerald-600`
- Secondary:
  - `border border-gray-300 text-gray-700`
  - `hover:bg-gray-100`

### Inputs

- `border-gray-300 rounded-lg px-3 py-2`
- `focus:ring-2 focus:ring-emerald-500`
- `focus:border-emerald-500`

### Cards

- `bg-white rounded-2xl shadow-sm p-4`
- `border border-gray-100`

### Containers

- `max-w-6xl mx-auto px-4`

## 5. Иконки

- Использовать `lucide-react`.
- Только единый outline-стиль иконок.
- Базовый размер: `18–22px`.
- Цвет:
  - по умолчанию `text-gray-500`;
  - для активных/акцентных элементов `text-emerald-500`.

## 6. Layout и отступы

- Использовать единый ритм по Tailwind spacing scale.
- Предпочтительные значения:
  - `gap-4` / `gap-6`;
  - `p-4` / `p-6`.
- Не допускать визуально “сжатых” экранов.
- Делить страницы на понятные секции с читаемой иерархией.

## 7. Типографика

- Заголовки: `text-2xl` / `text-3xl font-semibold`.
- Основной текст: `text-sm` / `text-base text-gray-700`.
- Вторичный (muted) текст: `text-gray-500`.

## 8. Правила дальнейшей разработки

- Не делать редизайн компонентов без явного запроса.
- Не добавлять новые цветовые палитры.
- Переиспользовать существующие стили и UI-паттерны.
- Поддерживать консистентность интерфейса на всех страницах.
- Отдавать приоритет простоте и ясности вместо визуальной перегруженности.

## 9. Правило использования этого документа

- Этот документ обязателен для всех UI-изменений.
- При конфликте с локальными стилями приоритет у этого гайда, если не дано отдельное явное указание.
